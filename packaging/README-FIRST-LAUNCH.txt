Voxi 首次启动说明（自签名 / CI 构建）
=====================================

重要：本构建不是 Apple Developer ID 签名，也没有经过 Apple notarization。
本地发布包使用开发者自签名证书；GitHub Actions 构建使用 ad-hoc 签名。
macOS 的 Gatekeeper 默认不信任这类应用；从网络下载后首次启动可能被系统拦截。
这是已知限制，不是安装包损坏。

推荐安装步骤
------------
1. 先核对制品完整性：把下载的 Voxi.zip 的 SHA-256 与发布页/README 中记录的值比较
   （macOS 上执行：shasum -a 256 Voxi.zip）。
2. 解压后把 Voxi.app 拖入“应用程序”（/Applications）。
3. 在 Finder 中右键 Voxi.app → 选择“打开”→ 在系统提示中再次点“打开”。
   直接双击可能只会显示“无法验证开发者”。
4. 如果仍被拦截：
   打开 系统设置 → 隐私与安全性 → 安全性，点击“仍要打开”，再确认一次。
5. 只有在确认制品来源和 SHA-256 之后，才可以选择仅对这个 App 移除下载隔离标记：
       xattr -dr com.apple.quarantine /Applications/Voxi.app
   这不会关闭 Gatekeeper。

请勿使用 spctl --master-disable 或任何“关闭整个 Mac Gatekeeper”的做法。

首次运行需要的权限
------------------
- 麦克风：第一次按住快捷键录音时，系统会请求权限。拒绝后需要到
  系统设置 → 隐私与安全性 → 麦克风 中手动允许。
- 辅助功能：用于全局快捷键和把识别结果输入到当前应用。在首次引导或
  设置 → 通用 → 权限 中请求。未授权时识别结果仍会保留在菜单栏，可手动复制。
- 单键右 Option / Fn 需要辅助功能权限；授权后回到 Voxi 会自动重试注册。
- 更新版本时尽量使用同一张自签名证书；CI 的 ad-hoc 签名每次不同，系统可能
  重新要求麦克风/辅助功能授权。

数据与隐私
----------
- 录音只在一次识别流程内存在，结束后删除临时音频。
- 端点由你自己配置；Voxi 不提供托管服务，也没有 Voxi 账号。
- API Key / Access Key 保存在系统 Keychain；不保存识别历史。
- 看板只保存计数（时长、字数、次数），不保存转写文本。
- 更新 App 后首次读取密钥时，macOS 可能要求输入登录密码；请选择“始终允许”。

版本信息、bundle ID 和校验值见发布页提供的 manifest.txt。
